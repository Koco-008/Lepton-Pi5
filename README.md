Software Drivers and Applications for Communicating With the FLIR Lepton Camera
====

Use the code in this repository to add Lepton support to embedded Linux systems.

The upstream FLIR code targeted Linux 5.10. The `rpi5-kernel-6.18` branch is a
work-in-progress Raspberry Pi 5 port for Debian 13 / Raspberry Pi kernel
`6.18.34+rpt-rpi-2712`.
